# تقویم شمسی با مناسبت‌ها

این پروژه یک وب‌سایت تقویم شمسی است که مناسبت‌ها و تعطیلات رسمی ایران را نمایش می‌دهد. این پروژه با استفاده از HTML، CSS و جاوااسکریپت پیاده‌سازی شده و داده‌های آن از یک منبع قابل اعتماد استخراج شده است.

## ویژگی‌ها

- نمایش تقویم دقیق شمسی.
- بارگذاری پویای مناسبت‌ها برای هر سال به صورت جداگانه جهت بهینه‌سازی عملکرد.
- نمایش روزهای تعطیل با رنگ متفاوت.
- طراحی ساده و کاربرپسند.

## راه‌اندازی پروژه

برای راه‌اندازی این پروژه به صورت محلی، مراحل زیر را دنبال کنید:

### ۱. پیش‌نیازها

- پایتون نسخه ۳.۶ یا بالاتر
- یک مرورگر وب مدرن

### ۲. آماده‌سازی داده‌ها

داده‌های مناسبت‌ها در فایل `persian_holiday.db` (که در این مخزن قرار ندارد) ذخیره شده‌اند. برای تولید فایل‌های `JSON` مورد نیاز، ابتدا فایل دیتابیس را از [این لینک](https://raw.githubusercontent.com/samanzamani/PersianHoliday/main/persian_holiday.db) دانلود کرده و در ریشه پروژه قرار دهید.

سپس، اسکریپت زیر را اجرا کنید تا فایل‌های `JSON` سالانه در پوشه `events` ایجاد شوند:

```bash
python convert_db_to_json.py
```

### ۳. اجرای سرور محلی

از آنجایی که مرورگرها به دلایل امنیتی اجازه بارگذاری فایل‌های محلی را با استفاده از `fetch` نمی‌دهند، باید پروژه را از طریق یک سرور وب محلی اجرا کنید. برای این کار، از ماژول `http.server` پایتون استفاده کنید:

```bash
python -m http.server 8000
```

### ۴. مشاهده وب‌سایت

حالا می‌توانید با مراجعه به آدرس `http://localhost:8000` در مرورگر خود، وب‌سایت تقویم را مشاهده کنید.
