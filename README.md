# تقویم شمسی آنلاین

این پروژه یک وب اپلیکیشن تقویم شمسی است که مناسبت‌ها و تعطیلات رسمی ایران را با استفاده از یک API آنلاین نمایش می‌دهد. این پروژه با HTML، CSS و جاوااسکریپت خالص ساخته شده است و برای نمایش دقیق رویدادها به API `persian-calendar-api` متکی است.

## ویژگی‌ها

-   نمایش تقویم دقیق شمسی (جلالی).
-   بارگذاری پویای مناسبت‌ها و تعطیلات از یک API آنلاین برای اطمینان از به‌روز بودن داده‌ها.
-   رابط کاربری ساده و تمیز با قابلیت جابجایی بین ماه‌ها.
-   هایلایت کردن روزهای تعطیل و روز جاری.

## نحوه اجرا

این پروژه یک وب‌سایت استاتیک است و نیازی به فرآیند ساخت یا وابستگی‌های پیچیده ندارد. برای اجرای آن به صورت محلی، فقط به یک وب‌سرور ساده نیاز دارید.

۱. **کلون کردن مخزن:**
   ```bash
   git clone https://github.com/your-username/persian-calendar.git
   cd persian-calendar
   ```

۲. **اجرای یک وب‌سرور محلی:**
   از آنجایی که پروژه از `fetch` برای فراخوانی API استفاده می‌کند، باید از طریق یک سرور وب اجرا شود. ساده‌ترین راه استفاده از ماژول داخلی `http.server` پایتون است:
   ```bash
   python -m http.server 8000
   ```
   اگر پایتون را نصب ندارید، می‌توانید از هر وب‌سرور استاتیک دیگری مانند `live-server` در VS Code یا `npx serve` استفاده کنید.

۳. **مشاهده وب‌سایت:**
   مرورگر خود را باز کرده و به آدرس `http://localhost:8000` بروید.

## ساختار پروژه

-   `index.html`: فایل اصلی HTML که ساختار صفحه را تعریف می‌کند.
-   `style.css`: فایل CSS برای استایل‌دهی به تقویم.
-   `script.js`: کد جاوااسکریپت که منطق تقویم، جابجایی بین ماه‌ها و فراخوانی API برای دریافت مناسبت‌ها را مدیریت می‌کند.
-   `lib/`: شامل کتابخانه `jalaali-js` برای محاسبات تاریخ جلالی است.
